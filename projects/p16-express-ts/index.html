Project Overview

Build a Task Manager API entirely in TypeScript. Use Express with proper middleware architecture. Use Prisma ORM for database access (type-safe queries). Use Zod for request validation (compile-time + runtime). This is your first TypeScript backend project - learn the ecosystem, tooling, and patterns that modern startups use. After this, you can work in both Python and TypeScript backends.

Project Specification

  • User registration and login with JWT (bcrypt for password hashing)
  • Task CRUD: title, description, status (todo, in_progress, done), priority, due_date
  • Tasks scoped to users (users see only their own tasks)
  • Filtering, sorting, pagination on task list
  • Zod validation for all request bodies
  • Global error handling middleware
  • Request logging middleware
  • Environment-based configuration (dotenv)
  • Prisma schema with migrations
  • TypeScript strict mode enabled
📖

What to Read Before Starting

  • TypeScript fundamentals: types, interfaces, generics, enums (read TypeScript Handbook)
  • Express middleware pattern: app.use, error middleware, request pipeline
  • Prisma ORM: schema definition, migrations, client generation, type-safe queries
  • Zod: schema validation, type inference (z.infer)
  • Node.js project structure: src/, dist/, tsconfig.json, package.json scripts
  • REST API best practices with Express: route-Controller-Service-Repository layers

🔧

Implementation Steps

  1. Initialize TypeScript project (npm init, tsconfig.json, dependencies)
  2. Set up Prisma with PostgreSQL schema (User, Task models)
  3. Create Express app with middleware (cors, json, logger)
  4. Implement auth routes: register, login, JWT generation
  5. Build auth middleware (extract user from JWT)
  6. Implement task CRUD routes with Zod validation
  7. Add service layer with business logic
  8. Add repository layer with Prisma queries
  9. Add filtering, sorting, pagination with query params
  10. Add global error handler middleware
  11. Write tests with vitest/supertest
✓

Verification Goals

  • POST /api/auth/register creates user; POST /api/auth/login returns JWT
  • GET /api/tasks returns only authenticated user's tasks
  • Zod rejects invalid task data with proper error messages
  • Prisma query is fully type-safe (TypeScript catches column name typos at compile time)
  • Pagination: GET /api/tasks?page=2&limit=10 returns correct slice
  • Error middleware catches unhandled errors and returns consistent JSON
  • ts-node-dev reloads on file changes during development
